# Cognizant Digital Nurture 4.0 – Deep Skilling (.NET Full Stack Engineer)

## Overview

This repository contains the complete set of laboratory exercises, assignments, and projects completed as part of the **Cognizant Digital Nurture 4.0 (DN 4.0) Deep Skilling Program** for the **.NET Full Stack Engineer (FSE)** learning path.

The repository is organized module-wise and covers backend development, frontend development, database programming, software engineering principles, testing, version control, microservices, and modern web application development using Microsoft technologies.
